# スケジュール資料（保存用フォルダ）

練習・試合のスケジュールを **画像 / PDF** で保存しておく場所です。

```
スケジュール資料/
├── 練習/   … 練習スケジュールの画像・PDF
└── 試合/   … 試合スケジュールの画像・PDF
```

## 使い方
1. 共有された画像・PDFをこのフォルダの `練習/` または `試合/` に入れる。
2. サイトに表示したいときは、`data/schedule.json` にカードを1件追加し、`file` にここのパスを書く。
   - 例: `"file": "スケジュール資料/試合/2026-07_リーグ戦.pdf"`
3. `git add` → `git commit` → `git push` で公開サイトに反映されます。

> ファイル名は日本語でもOKですが、`空白` の代わりに `_`（アンダースコア）を使うと安定します。
