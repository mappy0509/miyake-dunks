# 🏀 三宅DUNKS チーム管理サイト

ミニバスケットボールチーム「三宅DUNKS」の運営チーム用サイトです。
**練習メニュー / スケジュール / SNS投稿予定** をスマホから一目で確認できます。

公開URL（デプロイ後に記載）: `https://mappy0509.github.io/miyake-dunks/`

---

## 📁 フォルダ構成

```
三宅DUNKS/
├── index.html              … サイト本体
├── assets/                 … デザイン(style.css)と動作(app.js)
├── data/                   … ★ ここを編集して中身を更新する
│   ├── practice.json       … 練習メニュー
│   ├── schedule.json       … 練習・試合スケジュール
│   └── sns.json            … SNS投稿予定カレンダー
└── スケジュール資料/        … ★ 共有された画像・PDFの保存用フォルダ
    ├── 練習/
    └── 試合/
```

## ✏️ 更新のしかた（3つのチームで分担）

### ① 練習メニュー班 → `data/practice.json`
**期（season）→ 曜日（day）→ チーム区分（全体 / Aチーム / Bチーム）** の3階層。
- `teams` … チーム区分の名前と表示順。
- `seasons[].name` … 期の名前（例「基礎期（4〜7月）」）。`summary` は説明文。
- `seasons[].days[]` … `day`（曜日）・`time`（時間）・`groups`（区分ごとのメニュー配列）。
- 各メニュー … `name`（見出し）・`time`（所要時間/任意）・`detail`（補足/任意）・`steps`（中の項目を箇条書きで並べる配列/任意）。
- メニューが無い曜日は `[]`（空）にすると「未設定」と表示されます。
- 期や曜日を増やしたいときは、同じ形のブロックをコピーして追加。

### ② スケジュール班 → `data/schedule.json` ＋ `スケジュール資料/`
1. 共有画像・PDFを `スケジュール資料/練習/` か `スケジュール資料/試合/` に保存。
2. `schedule.json` にカードを追加。`file` にそのパスを書くと「資料を開く」ボタンが出ます。

### ③ SNS（広報）班 → `data/sns.json`
`date`・`platform`・`caption`（キャプション）・`hashtags` を入れると、
カレンダーの該当日に🟠が付き、タップでキャプション/タグをコピーできます。

## 🚀 編集をサイトに反映する

```bash
git add .
git commit -m "内容を更新"
git push
```

push後、1〜2分で公開サイトに自動反映されます。

> JSONはカンマや括弧を1つ間違えると表示が崩れます。心配なときは編集後に
> [JSONLint](https://jsonlint.com/) などで貼り付けチェックすると安全です。
